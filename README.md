# Inntake

[![The Inntake inn, with a sunlit cabinet of books and bottles and a wooden mallet on the floor](readme/inn.jpg)](https://inntake.app/)

Paste a link, leave yourself a note and file it in a collection when you like. Save in your browser, download a JSON backup or sync your library through a private GitHub repository.
