# Inntake

[![The Inntake inn, with a sunlit cabinet of books and bottles and a wooden mallet on the floor](readme/inn.jpg)](https://inntake.app/)

Paste a link, leave yourself a note and file it in a collection when you like. Your library stays in this browser. Download a JSON backup to take it with you.

[Open your library](https://inntake.app/app/) · [Wander around the inn](https://inntake.app/)
